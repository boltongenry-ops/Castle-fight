# Castle Fight

ПК и Android: строительство армии, битвы рас и сетевая игра на общем сервере.

## Скачать

- [Лаунчер для Windows](https://github.com/boltongenry-ops/Castle-fight/releases/latest/download/CastleFight-Launcher.exe)
- [Один APK для Android](https://github.com/boltongenry-ops/Castle-fight/releases/latest/download/CastleFight-Android.apk)
- [Portable EXE без установки лаунчера](https://github.com/boltongenry-ops/Castle-fight/releases/latest/download/CastleFight-Portable.exe)

Лаунчер сверяет файлы с `release.json`, докачивает только изменённые части,
позволяет войти в существующий сетевой аккаунт и запускает игру. Пароль не
сохраняется. Токен повторного входа защищён Windows DPAPI. Игра с ботами
доступна без входа. Файлы игры находятся в `%LOCALAPPDATA%/CastleFight/Game`.

На Android установите APK один раз. Дальше совместимые ресурсы проверяются и
докачиваются при запуске, а обновления приложения предлагаются внутри игры:
**Настройки → Обновления**. Игра скачивает APK и проверяет его; Android просит
подтвердить установку. Доступ к установке разрешается только при обновлении.
Аккаунт, настройки и кэш сохраняются. Первый запуск требует интернета.

## Правка и публикация

Редактируемый код лаунчера, Unity и каталоги рас находятся в `source/`.
Изменения кода требуют пересборки соответствующей версии игры. Модели,
сохранённые сцены и исходные архивы ассетов остаются в основном Unity-проекте;
эта папка исходников дополняет его, а не заменяет весь большой проект.

Готовые файлы хранятся в Releases. После проверки сборки публикация нового
`release.json` в ветку `main` переключает канал обновлений. В нём указаны
версия, размеры, контрольные суммы и диапазоны файлов в portable EXE.
Лаунчер читает только этот каталог и сохраняет загрузку при обрыве.

Для отдельного обновления ресурсов опубликуйте совместимый Android-каталог
и укажите его URL в `android.contentManifest`. `minimumPlayerVersion`
запрещает старому приложению загружать ресурсы для несовместимого кода.
Опубликованные SHA-файлы ресурсов сохраняются для старых установок.

Тесты выпуска проверяют изменённые механики, реальный portable, обновление
файлов и состав APK. Физический телефон в этом выпуске не тестировался.
