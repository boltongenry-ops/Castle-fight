# Туман, высший строитель и испытания 0.34

Выпуск Windows + Android code22. Основа — main 0.33.2, включая оптимизацию 0.33.1. Классические модели, баланс рас, сервер, аккаунты и сетевой ранг сохраняются.

## Туман

«Настройки → Простое затемнение»: нейтральный чёрный слой с максимальной непрозрачностью 104/255 вместо сине-серой заливки 200/255. Земля остаётся видна, живые враги и выбор скрытых целей подчиняются прежней FogGrid. Альтернатива — плотная чёрная тень. Маски по-прежнему 160×90 и 256×128; нет новых частиц, моделей, render textures или ассетов. Проекция обновляется в каждом кадре движения камеры, вместо ограничения 12 Гц. Уточнение высоты прекращается только при точном совпадении высоты двух итераций: оставшиеся итерации дали бы идентичные точки.

Options сохраняет прежний набор полей выпущенного player-data: настройка вынесена в ConditionalWeakTable и сохраняется в JSON явно. Это исправляет расхождение исходника Git 0.33.2 с фактическим бинарником. Черновик настроек копирует значение независимо, отмена не применяет переключатель.

## Высший строитель на Android

Старый UltimateBuilder.asset содержит массивы всех 258 строк и ссылки на модели почти всех рас. Загрузка этого ScriptableObject целиком создаёт большой пик памяти. Это правдоподобная причина вылета при запуске «Сборной армии», но без лога конкретного телефона причина native crash окончательно не подтверждена.

Теперь загружается небольшой runtime PcRacePack с прежними размерами массивов и разреженным заполнением. До начала раунда делается один обычный draw из 11 слотов, предзагружаются только модели выбранных цепочек улучшений для нужной стороны. В сети используется ровно серверный ultimate_loadouts. Дополнительные призывы, превращения и единичные модели учебника получают ассет по существующему пути лениво. Иконки загружаются по мере использования. Новый раунд освобождает старую оболочку до UnloadUnusedAssets. Пакеты LZ4 остаются прежними: загрузка контейнера не означает LoadAsset всего race pack.

UltimateAssetMap034 — таблица путей из GUID исходного UltimateBuilder.asset; tools/generate_ultimate_asset_map.py воспроизводит её после restore. Все 1688 уникальных путей сверены со списками существующих Android-пакетов. Порядок строк, GUID, формула производства, состав допустимых наборов и баланс не меняются. Все 33 SHA-пакета и каталог 0.33.0 сохраняются.

## Кампания

30 испытаний: исходные 18 ID сохранены, добавлены 12. Включены все 16 рас, в том числе кентавры. Новые ограничения действуют на стороне игрока: без защитных башен, специальных построек, покупок в замке, максимум производителей. Как раньше, no_legends/no_rescue действуют на обе стороны. Дополнительные цели победы: живые оплаченные улучшенные здания и разные корневые ветки производителей. Очередь входит в лимиты; две ступени одной ветки не считаются разными ветками. Требования к времени и HP замка комбинируются с составом армии. Два задания используют сложного бота.

Мастерство профиля: опыт, уровень и звание вычисляются из сохранённых ID первых прохождений. Старые прохождения сразу учитываются без повторной выдачи жетонов; повтор улучшает только рекорд времени. Порог уровня n: 100×(n−1)×n/2. В интерфейсе испытаний и собственном профиле явно указан локальный прогресс на устройстве. Он не меняет PvP-рейтинг сервера и не синхронизируется между устройствами. Боевых бонусов за уровень нет.

## Проверки и границы

BuildChallenge034.Validate проверяет правила/сохранение и пути моделей. PcChallenge034Checks запускает все 30 сценариев в реальном Windows player; PcFogChecks проверяет нейтральные пиксели, скрытие противника, независимый черновик настройки и проекцию на 24 движущихся кадрах. Проверяется финальный portable, затем подпись, версия/код и встроенный каталог настоящего APK. Пакет Android и сертификат сохраняются.

Физический Android и конкурентная проходимость всех 30 заданий не сертифицированы. Замер тумана на Windows под нагрузкой сборки не является мобильным FPS. Состояние остального плана оптимизации — [OPTIMIZATION-STATUS.ru.md](OPTIMIZATION-STATUS.ru.md).
