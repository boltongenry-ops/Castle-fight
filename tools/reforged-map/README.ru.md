# Оформление карты Reforged

Пакет меняет девять атласов поверхности и статическую геометрию декораций по ключам NativePlacement.modelKey. В исходной сцене стены, деревья и растения сохраняют координаты и масштаб размещения. Здания игроков, юниты, эффекты, вода, туман и коллайдеры используют свои обычные источники.

## Сборка контента

1. Установите Python с Pillow и requests и .NET SDK 10. Задайте переменную окружения W3ModelViewerRoot с путём к исходникам используемого конвертера W3ModelViewer и CF_MAP_WORK с путём к рабочему каталогу.
2. Запустите collect.py. Скрипт берёт девять ID из Resources/map-terrain.json, разрешает их через TerrainArt/terrain.slk и получает diffuse DDS из HD-архива. Для статических декораций берутся исходные MDX и их diffuse-текстуры. Список успешно разрешённых вариантов записывается в content/catalog.txt.
3. В отдельном проекте Unity той же версии включите пакеты com.unity.nuget.newtonsoft-json и com.unity.modules.assetbundle. Поместите BuildMapArt.cs в Assets/Editor. Задайте CF_MAP_INPUT равным каталогу content, CF_MAP_OUTPUT равным каталогу результата. Запустите Unity с -executeMethod BuildMapArt.Bake для Win64 и Android. Пакеты содержат отдельные адреса для девяти текстур, мешей, материалов в виде ссылок на текстуры и каталога.
4. При изменении пакета выпустите его под новым адресом, обновите контрольные суммы MapPackHashes и BaseUrl в ReforgedMap, пересоберите клиенты. Классическая установка работает без этого дополнения.

Для проверки готового Windows-клиента используйте --map-view west --pc-map-art-check <папка-отчёта> --pc-settings-file <отдельная-папка>/settings.json. Прогон скачивает пакет, применяет его, сравнивает сцену при возврате к классике и удаляет скачанный файл из тестовой папки.
