# Тестовая сборка Чёрной Руки

Установите или обновите обычную версию Castle Fight до 0.42.2 через лаунчер. После этого запустите CastleFight-BlackHand-Preview.exe из GitHub Release. Первый запуск проверит файлы 0.42.2 и создаст отдельную копию игры в локальном каталоге CastleFight/Preview. Для копии понадобится около 3 ГБ. Версия и профиль основной игры доступны в обычном лаунчере, тестовая версия хранит собственные настройки и профиль.

В меню выберите «Играть с ботом», «Клан Чёрной Руки» и включите аспекты. В начале раунда выберите «Железный устав» или «Осадная доктрина». В тестовом релизе доступна Windows-версия для локального боя.
